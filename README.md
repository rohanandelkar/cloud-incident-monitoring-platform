\# Cloud Incident Monitoring Platform



A cloud-based application monitoring and incident management platform built using AWS.



\## Problem



Modern applications need reliable infrastructure monitoring, automatic failure detection, and scalable deployment.



This project demonstrates how AWS services can be combined to build a highly available and monitored application infrastructure.



\## Current Features



\- FastAPI backend

\- Application health monitoring

\- REST API

\- Interactive API documentation

\- Server identification

\- Health check endpoint



\## Planned AWS Architecture



\- Amazon EC2

\- Amazon EBS

\- Amazon AMI

\- Application Load Balancer

\- Target Groups

\- Auto Scaling Groups

\- Amazon CloudWatch

\- Amazon SNS

\- Amazon RDS

\- IAM

\- Amazon S3

\- Route 53

\- Docker

\- GitHub Actions

\- Terraform
